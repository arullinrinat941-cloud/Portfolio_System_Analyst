# Портфолио: системный аналитик (учебный проект)

**Автор:** Яруллин Ринат Анасович  
**Цель:** Продемонстрировать навыки системного анализа на примере проекта «Task Manager Lite»

---

## О проекте

Проект представляет собой **комплект документов и диаграмм** для гипотетической системы управления задачами в небольшой команде (до 5 человек).

**В портфолио входят:**

- Функциональные и нефункциональные требования  
- Use Case, BPMN, ER-диаграммы  
- Диаграмма переходов статусов  
- Прототип интерфейса (описание + схематические изображения)  
- Предполагаемый технологический стек
