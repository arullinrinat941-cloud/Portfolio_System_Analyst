##  Цель проекта

Разработка парсера для сбора объявлений с платформы Avito с целью получения списка объектов недвижимости (частные дома/коттеджи в Московской области), **не имеющих готового ремонта**.

**Бизнес-цели:**
- Анализ рынка недвижимости
- Поиск объектов для перепродажи / инвестиций
- Ускорение ручного поиска объявлений

---

| Параметр | Значение |

| География | Московская область |
| Категории | коттеджи, частные дома, дачи, таунхаусы |
| Исключения | квартиры |

---

##  Логика фильтрации

###  Включаем (нет ремонта)
- без ремонта
- требуется ремонт
- черновая отделка
- под отделку
- коробка дома
- без внутренней отделки

###  Исключаем (есть ремонт)
- евроремонт
- дизайнерский ремонт
- с ремонтом
- готов к проживанию
- заезжай и живи

Фильтрация выполняется по **ключевым словам** в заголовке и описании.

##  Собираемые поля

| Поле | Описание |
|------|----------|
| заголовок | Название объявления |

| дата публикации | Дата размещения (если доступна) |

---
Архитектура решения

Проект построен по модульному принципу, каждый компонент отвечает за свою зону ответственности:

| Модуль | Назначение |
|--------|------------|
| `parser.py` | Загрузка страниц и получение HTML-кода |
| `extractor.py` | Извлечение данных из карточек объявлений |
| `filter.py` | Логика фильтрации "без ремонта" (ключевые слова) |
| `storage.py` | Сохранение результатов в CSV / Excel |
| `main.py` | Оркестрация процесса (управляющий скрипт)
