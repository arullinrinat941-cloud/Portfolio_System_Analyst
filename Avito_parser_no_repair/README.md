Парсер Avito — поиск коттеджей без ремонта (Московская область)

## Задача
Разработать парсер для сбора объявлений с Avito (дома, коттеджи, дачи в Подмосковье), в которых **нет готового ремонта**.

## Решение
-  Написан парсер на Python + Playwright
-  Реализована фильтрация по ключевым словам
-  Сохранение в Excel и CSV

 Логика фильтрации

| Включаем (нет ремонта) | Исключаем (есть ремонт) |
|------------------------|-------------------------|
| без ремонта | евроремонт |
| требуется ремонт | дизайнерский ремонт |
| черновая отделка | с ремонтом |
| под отделку | готов к проживанию |
| коробка дома | заезжай и живи |
| без внутренней отделки | |

## Файлы
- `Отчёт_о_выполнении_ТЗ.docx` — полный отчёт
- `demo_parser.py` — код демо-версии
- `avito_no_repair_demo.xlsx` — результат (Excel)
- `avito_no_repair_demo.csv` — результат (CSV)

## Сложности
Avito блокирует автоматические запросы (капча, 403).  
В демо-версии используются тестовые данные.  
Для продакшена нужны: прокси, ротация IP, сервисы обхода капчи.
